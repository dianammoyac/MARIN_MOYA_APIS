# Fuente del selector territorial

`municipios.json` incorpora el listado de departamentos y ciudades del proyecto
[colombia-json](https://github.com/marcovega/colombia-json/blob/master/colombia.min.json)
de Marco Vega, disponible bajo licencia MIT. Se quitaron los identificadores
internos y una ciudad duplicada en Magdalena, se organizó el orden alfabético
y se agregó Bogotá D.C. como distrito seleccionable. La fuente fue consultada
el 3 de octubre de 2026. Para mantenerla actualizada, contrastar cambios
territoriales con el [listado DIVIPOLA de datos.gov.co](https://www.datos.gov.co/resource/gdxc-w37w.json).
